## What it is

A full-stack event ticketing and booking platform built with React and
Express — users browse events, add tickets to a cart, and check out securely.

## Highlights

- **End-to-end booking flow** — event listings, ticket availability, cart,
  and checkout with credit card payment support.
- **Classic client/server split** — a React front end talking to an Express
  API, the whole pipeline hand-rolled.
